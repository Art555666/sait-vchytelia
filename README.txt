ОСВІТНІЙ ПОРТАЛ «ІНФОРМАТИКА» — ВЕРСІЯ 8

Як відкрити сайт:
1. Розпакуйте архів у папку.
2. Відкрийте index.html у сучасному браузері.

Що є в цій версії:
- Збережені попередні сторінки та матеріали для 5–11 класів.
- Оновлені спільні елементи навігації.
- Пошук за назвами сторінок і ключовими словами.
- Перемикач темної та світлої теми; вибір зберігається локально.
- Інтерактивні тести для 5–11 класів: по 5 запитань на кожен клас, пояснення до відповідей і підсумок у балах та відсотках.
- Найкращий результат для кожного класу зберігається локально у браузері.
- Адаптивні стилі для мобільних екранів.

Обмеження:
- Пошук працює за вбудованим індексом сторінок, який потрібно оновлювати при додаванні нових розділів.
- Результати тестів не надсилаються вчителю та не синхронізуються між пристроями.
- Форма контактів відкриває поштовий застосунок; для надсилання робіт і облікових записів потрібен сервер або зовнішній сервіс.

Файли логіки: script.js, theme.js, search.js, tests.js.


Зміни версії 6:
- Завершено редизайн головної сторінки: новий hero-блок, швидкі посилання, картки класів 5–11 та блок про навчальний підхід.
- Додано адаптивні стилі для малих екранів і підтримку зменшення анімацій.
- Покращено клавіатурний фокус, активний пункт навігації та доступність мобільного меню.
- Виправлено контраст кнопок ghost у світлих навчальних картках.
- Збережено наявні сторінки, пошук, теми й демонстраційні тести.


Оновлення v7: узгоджене оформлення внутрішніх сторінок, декоративні фони заголовків, навігаційні «хлібні крихти», посилання для переходу до основного вмісту та покращення темної/світлої теми.
