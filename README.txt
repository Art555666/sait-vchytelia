ОСВІТНІЙ ПОРТАЛ «ІНФОРМАТИКА» — ВЕРСІЯ 10

Статичний навчальний сайт для GitHub Pages або іншого статичного хостингу.

Запуск: відкрийте index.html у браузері. Для публікації завантажте всі файли й папки до кореня репозиторію.

Нові сторінки, створені на основі наданого PDF-експорту Google Sites:
- methodical.html — методичний паспорт уроку;
- lesson.html — розробка 45-хвилинного уроку;
- practical.html — три рівні практичних робіт;
- interactive.html — вікторина, LearningApps і Scratch;
- assessment.html — оцінювання за ГР1–ГР4 та методичні картки.

Сторінка materials.html доповнена навігацією до нового авторського навчального модуля.
Зовнішні Google Drive / Forms / Slides, LearningApps та Scratch залишаються зовнішніми ресурсами й потребують відповідних прав доступу.

Технології: HTML, CSS, JavaScript.
